# Releasing Su2al

Both native builds need, once per terminal:

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@17 ANDROID_HOME=$HOME/Library/Android/sdk
```

## Play Store bundle

```bash
npx expo prebuild -p android --clean --no-install
cd android && ./gradlew bundleRelease \
  -Pandroid.injected.signing.store.file=$HOME/.su2al-keys/upload.keystore \
  -Pandroid.injected.signing.store.password=... -Pandroid.injected.signing.key.alias=upload \
  -Pandroid.injected.signing.key.password=...
```

Output: `android/app/build/outputs/bundle/release/app-release.aab` (copy to `~/Desktop/Su2al-<version>.aab`).
Leave `EXPO_PUBLIC_API_URL`, `EXPO_PUBLIC_NO_ADS` and `EXPO_PUBLIC_APP_VARIANT` unset, so the bundle uses the live server and live ads.
Set `EXPO_PUBLIC_REVENUECAT_ANDROID_KEY` once RevenueCat is set up (until then the "remove ads" card stays hidden).

**Upload key:** `~/.su2al-keys/upload.keystore`, alias `upload`; passwords in `~/.su2al-keys/keystore.properties` (readable only by your Mac user, never committed).
SHA-256: `F2:F1:71:67:E2:9F:7D:66:97:2A:AA:D0:2C:4E:5F:63:3F:2B:47:9A:A3:B0:00:B0:33:2C:AE:B0:0A:A3:A6:5D`
**Back up that folder.** With Play App Signing, Google holds the real signing key; a lost upload key can be reset through Play support, but it takes days.

Before every new upload, bump `version` and `android.versionCode` in `app.json`.

## Other builds

| Build | How | Notes |
|---|---|---|
| Dev client | `npx expo start --dev-client` + `./gradlew app:installDebug -PreactNativeArchitectures=arm64-v8a` | The Apple-silicon emulator is arm64. |
| Test APK | GitHub Actions `android-preview-apk.yml` on every push to `main` | Test ads, live server. |
| Store screenshots | `EXPO_PUBLIC_NO_ADS=1 EXPO_PUBLIC_API_URL=http://localhost:4100` + `assembleRelease` | Release builds block plain HTTP: add `android:usesCleartextTraffic="true"` to the generated manifest for this build only. Seed the local DB first. |

Icons and store art are generated by `scripts/art/build_icons.sh`, `feature.html` and `shot.html` (headless Chrome).
Listing text, data-safety and content-rating answers: `store/play-listing.md`.
